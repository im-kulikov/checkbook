# TabBar

Нижняя навигация телефона: Обзор · Операции · «+» · Входящие · Ещё.

- Центральная «+» открывает лист «Добавить»; отдельной плавающей кнопки нет.
- Бейдж «Входящих» считает только «Проверить» и «Не отправлено»; `aria-label` — «Входящие, 3 новых».
- Активная вкладка — `accent` и `aria-current="page"`. Внизу учитывается `env(safe-area-inset-bottom)`.
- На десктопе вместо панели — боковой список разделов.
