# SplitPart

Одна часть разделённого чека: категория, сумма, заметка; плюс строка остатка под всеми частями.

- Последняя часть получает остаток автоматически и помечена «остаток — подставлен сам».
- Остаток: 0 — `success` «✓ распределено»; больше 0 — `warning` «осталось распределить»; меньше 0 — `danger` «больше суммы чека». Сохранить можно только при 0.
