# PinPad

Клавиатура PIN из 6 цифр для разблокировки, когда Face ID или отпечаток недоступны.

- Пять неверных попыток подряд — пауза 5 минут с обратным отсчётом.
- Подпись рядом: «Блокировка экрана, не шифрование», если устройство не поддерживает PRF.
- Кнопки 64 px; точки ввода озвучиваются числом («введено 2 цифры из 6»).
