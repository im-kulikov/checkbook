# Logo

Знак «Чекбук»: чек-книжка с галочкой на скруглённой плитке. Два варианта: светлый (`mark.svg`) и тёмный (`mark-dark.svg`), и lockup со словом «Чекбук» (`lockup.svg`, `lockup-dark.svg`).

- Размеры знака: 64 px (приветствие, заставка — до 112 px), 40 px (шапки, диалоги). Меньше 28 px не используется.
- Только **inline SVG**, не `<img>`: рядом кладутся оба варианта, показывается нужный по `[data-theme="dark"]` (`[data-lm="d"]{display:none}` и обратный селектор). Цвета знака — фиксированные, токены ему не нужны.
- Lockup — на экранах, где есть место по горизонтали (десктоп, «О приложении»); на телефоне — знак и название отдельной строкой.
- Свободное поле вокруг знака — не меньше четверти его стороны. Не перекрашивать, не вращать, не ставить на цветной фон.
- Файлы: `mark.svg`, `mark-dark.svg`, `lockup.svg`, `lockup-dark.svg`.
