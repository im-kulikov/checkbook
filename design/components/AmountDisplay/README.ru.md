# AmountDisplay

Сумма: табличные цифры, узкий неразрывный пробел между разрядами, знак ₽ после числа.

- Размеры: XL 36 px (итог периода), L 28 px (итог категории, сумма операции), M 17 px (строки).
- Траты показываются без знака. Возврат — «+» и цвет `success`, всегда с тегом или подписью «возврат». Перевод своему — цвет `text-2`.
- В итогах без копеек, в операциях с копейками. Сумма никогда не обрезается.
