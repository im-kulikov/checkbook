# BottomSheet

A bottom sheet over the screen with a `scrim` dimmer: «Добавить» ("Add"), category selection, filters, payee merging.

- Heights: fit to content, half the screen, full screen. A handle on top and a «Закрыть» ("Close") button: swiping is not the only way to close it.
- Focus is trapped inside the sheet; Esc and «Назад» ("Back") close it.
