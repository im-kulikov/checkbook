# BottomSheet

Нижний лист поверх экрана с затемнением `scrim`: «Добавить», выбор категории, фильтры, слияние получателей.

- Высоты: по содержимому, половина экрана, весь экран. Ручка сверху и кнопка «Закрыть» — свайп не единственный способ закрыть.
- Фокус заперт внутри листа, Esc и «Назад» закрывают его.
