# ListRow

Строка списка внутри карточки `ck-list`: навигация (›), значение справа, переключатель, «ключ–значение» только для чтения.

- Высота от 56 px, двухстрочная — 64 px; разделитель `divider` между строками.
- Заголовок обрезается многоточием, значение — никогда.
- Группы строк получают заголовок секции `ck-section` («Сегодня, 15 окт · −27 840 ₽»).
