# ListRow

A list row inside a `ck-list` card: navigation (›), a value on the right, a switch, a read-only "key–value" pair.

- Height from 56 px, two-line — 64 px; a `divider` separator between rows.
- The title is truncated with an ellipsis, the value never is.
- Groups of rows get a `ck-section` section heading («Сегодня, 15 окт · −27 840 ₽» ("Today, 15 Oct · −27 840 ₽")).
