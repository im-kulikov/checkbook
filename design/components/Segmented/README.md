# Segmented

A switch of 2–4 mutually exclusive options.

- Where: the operation kind (Трата / Возврат / Перевод своему — "Expense / Refund / Transfer to own"), appearance, «За месяц / За всё время» ("For the month / For all time") on a budget.
- `role="radiogroup"`; the segments have `role="radio"` and `aria-checked`. The selected one is `surface` with a `divider` border and bold text.
