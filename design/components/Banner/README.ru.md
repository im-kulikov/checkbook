# Banner

Плашка на экране: информация, предупреждение, ошибка, офлайн. Значок + текст + необязательное действие.

- Действие на цветном фоне — подчёркнутый текст цвета `text`, а не `accent`: так контраст не зависит от фона.
- Ошибки без кодов: «ИИ сейчас недоступен», «GitHub недоступен — всё сохранено на телефоне».
