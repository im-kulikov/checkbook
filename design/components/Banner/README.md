# Banner

An on-screen strip: information, warning, error, offline. Icon + text + an optional action.

- The action on a coloured background is underlined text in the `text` colour, not `accent`, so the contrast does not depend on the background.
- Errors carry no codes: «ИИ сейчас недоступен» ("AI is unavailable right now"), «GitHub недоступен — всё сохранено на телефоне» ("GitHub is unavailable — everything is saved on the phone").
