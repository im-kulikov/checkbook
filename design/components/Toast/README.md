# Toast

A short confirmation at the bottom of the screen: «Операция удалена» ("Operation deleted"), «Категория в архиве» ("Category archived"), «Получатели объединены» ("Payees merged").

- Inverted colours (`text` as the background, `bg` as the text): equally visible in both themes.
- With an «Отменить» ("Undo") action it stays for at least 10 seconds; `role="status"`, `aria-live="polite"`.
