# EmptyState

The empty state of a section: an icon, a heading, a single line of explanation and an action.

- Examples: «Операций пока нет» ("No operations yet") + «Добавить чек» ("Add a receipt"); «Ничего не нашлось» ("Nothing found") + «Сбросить фильтры» ("Reset filters"); «Всё разобрано» ("All sorted").
- The full-screen variant is used on the «Приветствие» ("Welcome"), «Доступ закрыт» ("Access closed") and «Шлюз недоступен» ("Gateway unavailable") screens.
