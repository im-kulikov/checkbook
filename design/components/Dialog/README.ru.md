# Dialog

Окно подтверждения: заголовок-вопрос, одно-два предложения о последствиях, «Отмена» и действие.

- Для разрушительного действия кнопка `danger` справа, фокус по умолчанию — на «Отмена».
- В светлой теме — `surface` и тень `shadow-float`; в тёмной — `surface-2` с рамкой `divider`, без тени.
