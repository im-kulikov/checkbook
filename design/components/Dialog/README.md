# Dialog

A confirmation window: a heading phrased as a question, one or two sentences about the consequences, «Отмена» ("Cancel") and the action.

- For a destructive action the `danger` button is on the right, and the default focus is on «Отмена».
- In the light theme — `surface` and the `shadow-float` shadow; in the dark theme — `surface-2` with a `divider` border, no shadow.
