# SuggestionRadio

A choice option with the reason for the suggestion: «по получателю» ("by payee"), «последняя» ("last"), «частая» ("frequent"), «ИИ» ("AI").

- Always the full category path. No more than three suggestions, then «Другая категория…» ("Another category…").
- The selected one has a 2 px `accent` border, an `accent-weak` background and a filled dot.
