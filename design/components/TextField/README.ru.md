# TextField

Поле ввода с подписью над ним, необязательной подсказкой и ошибкой под ним.

- Варианты: текст, сумма (с калькулятором «1200+350»), дата и время (нативные контролы), поиск, адрес, секрет (маска, «Вставить из буфера»).
- Обязательное поле помечено `*` цвета `danger`; ошибка — рамка `danger` 2 px и текст под полем, а не только цвет.
- Высота от 48 px; рамка `border` (контраст 3,99 / 3,94).
