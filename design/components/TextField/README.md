# TextField

An input field with a label above it, an optional hint and an error below it.

- Variants: text, amount (with a calculator, «1200+350»), date and time (native controls), search, address, secret (masked, «Вставить из буфера» ("Paste from clipboard")).
- A required field is marked with a `danger`-coloured `*`; an error is a 2 px `danger` border and text under the field, not colour alone.
- Height from 48 px; `border` frame (contrast 3.99 / 3.94).
