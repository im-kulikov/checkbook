# Illustration

16 иллюстраций для пустых и блокирующих состояний. Один стиль: плоско, обводка 2 px со скруглёнными концами (`--text-2`), фон-круг и акценты `--accent`. Холст 160 × 120 (`welcome` — 320 × 180), текста в картинках нет.

- Только **inline SVG** (не `<img>`, не `background-image`): цвета заданы как `var(--token, #светлое)`, поэтому тема переключается сама, отдельных тёмных файлов нет. Корневой `<svg>` уже `aria-hidden`: смысл передаёт заголовок рядом.
- Ширину задаёт CSS (`width:160px;height:auto`), экран-заставка — до 220 px. Бумага чека остаётся светлой в обеих темах.
- Располагается над заголовком `EmptyState` или по центру блокирующего экрана.

| Файл | Где |
| --- | --- |
| `empty-inbox` | Входящие пусто — «Всё разобрано» |
| `empty-operations` | Операций пока нет |
| `empty-search` | Ничего не нашлось |
| `empty-payees` | Получатели пусто |
| `empty-category` | В категории нет операций |
| `offline` | Нет сети, чеки в очереди |
| `update` | Обновите приложение |
| `access-closed` | Доступ закрыт |
| `install-ios` | Установка на iPhone |
| `install-android` | Установка на Android |
| `welcome` | Приветствие |
| `first-sync` | Первая загрузка |
| `camera-permission` | Разрешение камеры |
| `ai-assist` | ИИ: распознать / уточнить |
| `error` | Общая ошибка, «Шлюз недоступен» |
| `budget-over` | Бюджет превышен (необязательно) |
