# SyncIndicator

Постоянный индикатор синхронизации в шапке корневых экранов: значок + текст.

- Состояния: «Синхронизировано» (`success`), «N в очереди» (`warning`), «Нет сети · N ждут» (нейтральный), «Доступ закрыт» (`danger`).
- Нажатие ведёт в «Настройки → Синхронизация». Ошибки отправки дублируются во «Входящих».
