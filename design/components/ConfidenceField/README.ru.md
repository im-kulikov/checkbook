# ConfidenceField

Поле с результатом распознавания: показывает значение, уровень уверенности и источник.

- Высокая (≥ 0,9): обычное поле, ✓ и источник цветом `success` («из QR», «из текста PDF»).
- Средняя (0,6–0,9): фон `warning-weak`, рамка `warning` 2 px, «! проверьте».
- Низкая или пусто: фон `danger-weak`, рамка `danger` 2 px, «? не распознано»; подтвердить форму нельзя.
- После правки человеком — нейтральное «вручную».
- Скринридер читает «Сумма, 12 500 рублей, из QR, точно» — уровень всегда есть текстом.
