# TreeRow

Строка дерева категорий: название, итог ветки, полоса доли и раскрытие поддерева на месте.

- Отступ уровня — 16 px; у корня полужирное начертание.
- Режимы: просмотр (Обзор), выбор (лист выбора категории, кнопка «Выбрать этот уровень»), правка (меню «Переименовать», «Перенести в…», «Бюджет…», «В архив»).
- Траты, отнесённые прямо на родителя, — строка «Напрямую в „Стройка“» цветом `text-2`.
- `role="treeitem"`, `aria-level`, `aria-expanded`, `aria-selected`.
