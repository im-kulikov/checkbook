# Button

Кнопка действия: одна главная (`primary`) на экран, остальные — `secondary`, `text` или `danger`.

- Размеры: M — 44 px, L — 52 px (главное действие внизу экрана, на всю ширину).
- Подпись называет действие и объект: «Сохранить в Стройка › Электрика», «Отозвать доступ».
- `danger` — только для разрушительных действий, и всегда с подтверждением в `Dialog`.
- Недоступная кнопка — `disabled` и рядом причина текстом («распределите ещё 1 000 ₽»).
- Токены: `accent`, `on-accent`, `surface`, `border`, `danger`; фокус — кольцо `focus`.
