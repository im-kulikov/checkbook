# QRBlock

QR-приглашение участника: зашифрованный ключ в строке `checkbook:1:…`, белая подложка в любой теме, тихая зона не меньше 4 модулей.

- Показывается по нажатию и гаснет через 2 минуты с обратным отсчётом. Кнопок «Сохранить» и «Поделиться» нет.
- Рядом — 12-значный код крупно, тремя группами по 4 цифры, с подсказкой «скажите голосом».
