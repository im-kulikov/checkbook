# QRBlock

A member invitation QR: an encrypted key in a `checkbook:1:…` string, a white backing in any theme, a quiet zone of at least 4 modules.

- It is shown on tap and goes dark after 2 minutes, with a countdown. There are no «Сохранить» ("Save") or «Поделиться» ("Share") buttons.
- Next to it is a 12-digit code in large type, in three groups of 4 digits, with the hint «скажите голосом» ("say it aloud").
