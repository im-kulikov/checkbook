# illustrations/ — иллюстрации пустых и блокирующих состояний

16 SVG, один стиль: плоско, обводка 2 px со скруглёнными концами (`--text-2`), фон-круг, акценты `--accent`.
Холст 160 × 120 (`welcome` — 320 × 180). Текста в картинках нет.

## Как вставлять

- **Только inline** (содержимое файла прямо в разметку, например через `?raw`-импорт в Vite), не `<img>` и не
  `background-image`: из `<img>` CSS-переменные страницы не видны, и картинка всегда останется светлой.
- У корневого `<svg>` уже есть `aria-hidden="true" focusable="false"`: смысл передаёт заголовок пустого состояния
  рядом, а не картинка. `alt` не нужен.
- В файлах нет атрибутов `style` и `<style>` — совместимо с CSP приложения.
- Размер задаёт CSS (`width:160px;height:auto` или по ширине контейнера); `viewBox` сохраняет пропорции.
- Тема переключается сама: каждый цвет — `var(--token, #светлое-значение)`, токены берутся из
  `tokens/ck-tokens.css` (`[data-theme="dark"]`). Отдельные `-dark.svg` поэтому не нужны.
- Бумага чека светлая в обеих темах, как у `ReceiptThumb`: `--paper` `#FFFFFF`, `--paper-line` `#D7DAD3`,
  `--paper-ink` `#3D4247` (QR), `--paper-accent` `#1D6B57`, `--paper-accent-weak` `#E2EFEA`. Это не токены
  дизайн-системы: всегда действуют значения по умолчанию, если их специально не задать.
- Используемые токены: `--bg --surface --surface-2 --divider --text-2 --accent --on-accent --accent-weak --warning
  --warning-weak --danger --danger-weak`.

## Файл → экран / состояние

| Файл | Экран / состояние |
| --- | --- |
| `empty-inbox.svg` | Входящие пусто — «Всё разобрано» |
| `empty-operations.svg` | Операции пусто — «Операций пока нет» + «Добавить чек» |
| `empty-search.svg` | Поиск / фильтры пусто — «Ничего не нашлось» |
| `empty-payees.svg` | Получатели пусто |
| `empty-category.svg` | Категория пусто (в категории нет операций) |
| `offline.svg` | Нет сети — чеки ждут в очереди отправки |
| `update.svg` | «Доступна новая версия» / «Обновите приложение» |
| `access-closed.svg` | Доступ закрыт — ключ истёк или отозван |
| `install-ios.svg` | Установка на iPhone: «Поделиться» → «На экран Домой» |
| `install-android.svg` | Установка на Android: меню ⋮ → «Установить приложение» |
| `welcome.svg` | Приветствие (первый экран): чеки, семья в доме, дерево категорий |
| `first-sync.svg` | Первая загрузка данных семьи |
| `camera-permission.svg` | Разрешение камеры (снимок чека, QR) |
| `ai-assist.svg` | ИИ: распознать / уточнить чек |
| `error.svg` | Ошибка (общая), в т. ч. «Шлюз недоступен» |
| `budget-over.svg` | Бюджет категории превышен (необязательно) |

Образцы в обеих темах: `../preview-illustrations-light.png`, `../preview-illustrations-dark.png`.
