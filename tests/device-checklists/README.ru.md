# Ручные проверки на устройствах

[English version](README.md)

Кейсы, которые проверяются только руками на телефоне или скриптом оператора. Одна строка — один кейс, ID первым.
«Что сделать» и «Ожидается» можно сокращать, но не менять смысл. Результат записывается только по платформе и версии ОС.

| Файл | Что |
| --- | --- |
| `github.md` | настройки GitHub и подпись коммитов |
| `ios.md` | iPhone и iPad: iOS 26.x, iOS 27.0, iOS 18.x, если есть |
| `android.md` | Android, Chrome 125+ |
| `spike-report.md` | результаты раннего спайка на устройствах (установка, камера, хранилище) |

Формат строки (клетки устройств: ✓ прошло, ✗ не прошло — завести issue, «—» не относится):

```
| ID | Что сделать | Ожидается | iOS 26 | iOS 27 | iOS 18 |
| I09 | «Сфотографировать чек» → снять чек | без запроса доступа, QR прочитан | ☐ | ☐ | ☐ |
```

Сценарии UC-1…UC-16 записываются так же — в файл платформы, на которой их проходят.
